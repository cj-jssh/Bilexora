# 阅读器模块 (Reader)

## 概述

阅读器是 Bilexora 的核心功能模块，负责书籍内容的展示、阅读交互、翻译展示和翻译操作。阅读器页面为独立路由 `/reader/:bookId`，使用 `ReaderScreen` (ConsumerStatefulWidget) 实现。

**实现状态**: 部分实现（基础框架 ✅，交互细节 ❌/🔄）

---

### 数据结构

```
Chapter
 ├── index: int
 ├── title: String
 ├── blocks: List<ContentBlock>
 │    ├── Paragraph
 │    │    └── sentences: List<Sentence>
 │    │         ├── index: int
 │    │         ├── text: String
 │    │         ├── charOffset: int (全局句号)
 │    │         └── language: String?
 │    └── Image (imagePath, altText)
 └── sentenceCount: int
```

### 文件存储

```bash
library/books/{bookId}/
 ├── book.json              # Book 元数据
 ├── content.dat            # 章节+句子数据
 ├── content_{lang}.dat     # 译文缓存
 └── images/
     └── *.jpg/png
```

## 6. 操作逻辑需求（待重构）

根据产品要求，阅读界面的交互逻辑需要重新设计如下：

### 6.1 默认行为

- 阅读界面 **默认继承设置中的双语模式**，不进行任何回退
- 即：设置中双语开启则展示双语，关闭则只显示原文
- 用户不主动在阅读器内切换双语模式（菜单中的双语设置保留）

### 6.2 译文占位

- 每句译文区域使用 **固定大小的框** 进行占位（不再使用骨架屏动画）
- 占位框不因是否有译文而改变尺寸

### 6.3 点击交互

- **无译文时点击** → 显示 "暂无对应译文" 提示
- **再次点击 "暂无对应译文"** → 弹出引擎选择面板
- **有译文时点击** → 切换译文显示/隐藏（toggle）
- 引擎选择面板按引擎管理中 **设置的顺序** 展示（引擎管理页面的排序）

### 6.4 长按交互

- **长按原文或译文** → 选择复制（使用系统原生选区/上下文菜单）
- **长按已显示的译文 → 出现"重新翻译"选项**
- 选择"重新翻译"后，逻辑与无译文时点击一致（弹出引擎选择 → 确认引擎 → 翻译）

### 6.5 译文与原文的复制区域

- 原文和译文的**所有屏幕展示内容可以按完整显示区域进行选择复制**
- 不限制为单句复制，可以在整个段落内跨句跨译文选择

翻译完成等一次性提示使用全局顶部横幅（`showTopBanner`，`lib/core/utils/top_banner.dart`）：

- 从屏幕顶部滑入，驻留约 **2 秒**自动消失

- 阅读器与书库的“翻译完成”均改用此提示方式
