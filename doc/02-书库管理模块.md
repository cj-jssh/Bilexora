# 书库管理模块 (Library)

## 概述

书库管理模块负责书籍的导入、展示、搜索和管理。由 `LibraryScreen` 实现，通过 `libraryPathProvider` 访问存储路径。

**实现状态**: 框架完成 ✅，部分功能存在占位/待完善

---

## 1. 书籍导入

| 功能 | 状态 | 说明 |
|------|------|------|
| EPUB 导入 | ✅ 已实现 | `BookImporter.importEpub()` 完整支持 |
| TXT 导入 | ✅ 已实现 | `BookImporter.importTxt()` 按编码检测 |
| 文件选择器 | ✅ 已实现 | `file_picker` 库，支持 .epub / .txt |
| 导入进度 | ✅ 已实现 | 导入过程显示 SnackBar |
| 元数据提取 | ✅ 已实现 | 从 EPUB OPF 解析标题/作者/语言 |
| 导入位置选择 | ❌ 未实现 | 直接导入到默认位置 |
| 批量导入 | ❌ 未实现 | 需要逐文件选择 |
| 导入前预览 | ❌ 未实现 | |
