# 翻译引擎模块 (Translation)

## 概述

翻译引擎模块管理所有翻译能力，包括本地模型翻译和在线 AI 翻译。核心服务 `LocalTranslationService` 和 `TranslationFileManager` 处理翻译执行和持久化。

**实现状态**: 基础框架 ✅，部分功能完善中

### 3.1 批处理算法

```
单个 batch 限制: maxBatchTokens = 5000

  - 其他: 1 char = 1 token
```

### 4.1 文件格式

```binary
Header (16B):
  Magic: "TRLX" (4B)
  Version: uint16 (2B)
  Chapter Count: uint16 (2B)
  Chapter Index Offset: uint32 (4B)
  Chapter Index Length: uint32 (4B)

Translation Data:
  For each chapter:
    engineId (Varint + UTF-8 string)
    priority (Varint)
    For each sentence:
      text length (Varint)
      text (UTF-8)

Chapter Index:
  For each chapter:
    contentOffset (Varint)
    contentLength (Varint)
```
