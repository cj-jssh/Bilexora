# 设置模块 (Settings)

## 概述

设置模块提供应用全局配置界面，配置项存储在 SQLite library.db 的 `settings` 表中。

**实现状态**: 功能完整 ✅

## 0. 阅读设置页（母语 / 双语 / 逐句精听）

设置首页「阅读」分组下提供一个「学习」菜单项，点击跳转 `LearningSettingsScreen`（`lib/features/settings/learning_settings_screen.dart`），集中管理语言学习相关配置：

| 项目 | 说明 | 存储键 |
|------|------|--------|
| 母语 | 选择母语（13 种语言） | `native_language` |
| 双语阅读 | 开关 + 译文展示 + 学习语言 + 阅读习惯 | `bilingual_*` |
| 逐句精听 | 开启后逐句朗读 | `sentence_listening_enabled` |
| 朗读语速 | 滑块 0.2~0.7 | `sentence_listening_rate` |
| 自动连播 | 一句读完自动下一句 | `sentence_listening_auto` |
