# 设置模块 (Settings)

## 概述

设置模块提供应用全局配置界面，配置项存储在 SQLite library.db 的 `settings` 表中。

**实现状态**: 功能完整 ✅

---

1. **本地离线翻译** (local_bergamot) — type: local, 基于 Bergamot
2. **ChatGPT** (chatgpt) — type: online, OpenAI-compatible
