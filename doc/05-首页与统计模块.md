# 首页与统计模块 (Home)

## 概述

首页展示阅读统计、最近阅读书籍和通知信息。由 `HomeScreen` 实现，作为底部导航的默认 Tab。

**实现状态**: 框架完成 ✅，统计功能待完善

---

## 1. 首页展示

| 功能 | 状态 | 说明 |
|------|------|------|
| 最近阅读书籍 | ✅ 已实现 | `recentBooksProvider` 返回最近阅读的 3 本书 |
| 今日阅读时长 | ✅ 已实现 | `todayReadingSecondsProvider`, SQLite 聚合当天 |
| 周阅读统计 | ✅ 已实现 | `weeklySecondsProvider`, 返回 7 天数组 |
| 阅读目标进度 | ✅ 已实现 | 环形进度条 |
| 通知列表 | ✅ 已实现 | `notificationsProvider`, 翻译完成等通知 |
| 未读通知数 | ✅ 已实现 | `unreadNotificationCountProvider` 角标 |
| 页眉问候语 | ✅ 已实现 | 根据时间段显示"早上好/下午好/晚上好" |
| 周热度图 | ✅ 已实现 | 7 格热度条，颜色深浅表示阅读时长 |
