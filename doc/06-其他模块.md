## 3. 存储管理（Storage）

**实现状态**: 功能完整 ✅

### 3.1 存储用量

`StorageService`（`lib/core/storage/storage_service.dart`）递归统计应用占用空间：

| 目录 | 来源 |
|------|------|
| 文档目录 | library.db + books + bergamot_models + external_dicts |
| 缓存目录 | 系统应用缓存 |
| 临时目录 | 系统临时文件 |

设置页“存储用量”显示 `formatBytes` 格式化后的总占用，点击可重新计算。

### 3.2 清除缓存

二次确认后执行：

1. 清空系统临时目录
2. 清空系统应用缓存目录
3. 清空 `dictionary_cache` 词典缓存表（可重建的查词缓存）

不影响书籍、阅读进度、生词本与已翻译内容。清理后提示释放空间大小。

## 5. CI 发布流程

**实现状态**: 功能完整 ✅

`.github/workflows/release.yml` 在推送 `v*` 语义化 tag 时自动执行（手动 `workflow_dispatch` 亦可触发）：

| 阶段 | 说明 |
|------|------|
| 测试 | `flutter test`（Linux runner，装 cmake/ninja/libsqlite3） |
| 静态检查 | `flutter analyze`（`--no-fatal-infos --fatal-warnings`） |
| Android 构建 | 下载/复用 bergamot 原生 `.so`，`flutter build apk --release` (arm64) |
| iOS 构建 | macOS 补丁 vendored 依赖，未签名 IPA（`Bilexora_ios_{tag}_unsigned.ipa`） |
| 发布 | `gh release create`，上传 APK / IPA，同步 bergamot 二进制到复用 Release |

### 发布说明自动分类

对比**上一版本 tag → 当前 tag** 的提交，按 conventional commit 类型分类生成“更新日志”

| 分类 | 匹配前缀 |
|------|---------|
| ✨ 新功能 | `feat` |
| 🐛 Bug 修复 | `fix` |
| ⚡️ 性能优化 | `perf` |
| ♻️ 重构 | `refactor` / `revert` |
| 📝 其他变更 | 其余类型 |

无对应类型时显示 “> 无”。

## 6. 数据存储架构

### 6.1 文件系统

```bash
{ApplicationDocumentsDirectory}/
└── library/
    ├── library.db               # SQLite 数据库
    └── books/
        └── {bookId}/
            ├── book.json        # Book 元数据 JSON
            ├── content.dat      # 内容数据 (BILXDATA 二进制格式)
            ├── content_{lang}.dat  # 译文数据 (TRLX 二进制格式)
            ├── cover.jpg        # 封面图片
            └── images/          # 内嵌图片
```

### 6.2 SQLite 数据库 (library.db)

| 表名 | 用途 | 状态 |
|------|------|------|
| `books` | 书库索引 | ✅ |
| `reading_progress` | 阅读进度 | ✅ |
| `vocabulary` | 生词本 | ✅ (有表无数据) |
| `dictionary_cache` | 词典缓存 | ✅ (可一键清空) |
| `settings` | 键值对设置 | ✅ |
| `notifications` | 通知 | ✅ (未读红点/逐条已读) |
| `reading_time` | 阅读计时日志 | ✅ |
| `lookup_count` | 查词次数统计 | ✅ |
| `translation_status` | 翻译任务 | ✅ |

### 6.3 二进制协议

| 文件 | 魔数 | 用途 |
|------|------|------|
| `content.dat` | `BILXDATA` (8B) | 书籍内容（章节+句子） |
| `content_{lang}.dat` | `TRLX` (4B) | 译文缓存 |
